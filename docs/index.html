Musicalism is music theory in plain Ruby. Ask it for the V of A minor, the pivot between C and G, or the smoothest route from C major to F# major. It answers with notes, octaves and MIDI numbers, ready for the next bar.

Install

Musicalism needs Ruby 4.0 or later and has no runtime dependencies. Take it from GitHub:

gem 'musicalism', github: 'StupidCodeFactory/musicalism', tag: 'v0.1.0'

Then load it and start from a key:

require 'musicalism'
key = Musicalism::Key['C major']

A quick tour

Notes know their MIDI number

Scientific pitch notation, C4 = 60. Enharmonic notes are equal.

Musicalism::Note.new('C#4').to_midi   # => 61
Musicalism::Note.new('B#3') == Musicalism::Note.new('C4')  # => true

Keys give chords by numeral

In minor keys, V comes from harmonic minor.

key.chord(:V).to_midi                 # => [67, 71, 74]
Musicalism::Key['A minor'].chord(:V)  # => E major
key.numerals  # => [:I, :ii, :iii, :IV, :V, :vi, :vii]

Relatives and neighbours

The relative minor, the parallel key and both neighbours on the circle of fifths.

key.relative         # => A minor
key.parallel         # => C minor
key.dominant_key     # => G major
key.subdominant_key  # => F major

Modulate through a pivot

I, pivot, V and I of the new key, voice-led. The pivot is random unless you choose it.

key.modulate_to('G major', via: :vi).map(&:to_s)
# => ["C major", "A minor", "D major", "G major"]

Walk the key graph

Every key is a few closely related steps from every other. Each step has a pivot chord.

key.distance_to('F# major')   # => 6
key.modulate_through(key.path_to('D major'))
# => C, E minor, D, G, B minor, A, D major

Borrow from a passing key

Tonicize a degree for a bar without leaving the key.

key.tonicize(:ii)            # => D minor
key.secondary_dominant(:V)   # => D major, V/V
key.two_five(:IV)            # => G minor, C major
