Reference

Every class, every method

All examples run against musicalism 0.1.0 and show the real return values. Chords and keys print as names here for readability; they are Chord and Key objects. Notes print as pitch and octave, such as G4.

Note

A pitch with an octave, inside the piano range A0 to C8. Musicalism uses scientific pitch notation: C4 is middle C, MIDI 60. The octave belongs to the letter, so B#3 and C4 are the same MIDI note, and so are Cb4 and B3.

Note.new(note, octave = nil)

→ Note · raises Note::UnkownNoteError outside A0..C8

Takes a name with or without an octave, or a pitch and an octave apart. Without an octave the note sits in octave 4. Alterations go up to two sharps or two flats.

Musicalism::Note.new('C#4')     # => C#4
Musicalism::Note.new('E', 5)    # => E5
Musicalism::Note.new('Bbb')     # => Bbb4
Musicalism::Note.new('H4')      # raises Note::UnkownNoteError, "H4 is not a valid note"
Musicalism::Note.new('C9')      # raises Note::UnkownNoteError, "C9 is not a valid note"

Note.from_midi(midi_number)

→ Note, spelled with a natural or a single sharp

Musicalism::Note.from_midi(61)  # => C#4
Musicalism::Note.from_midi(60)  # => C4

Note.each { |note| … }

yields 88 notes, A0 to C8, one per MIDI number from 21 to 108

notes = []
Musicalism::Note.each { |note| notes << note }
notes.size                 # => 88
[notes.first, notes.last]  # => [A0, C8]

Note.parse_note_and_alteration(string)

→ Hash with :pitch, :octave, :alteration

Musicalism::Note.parse_note_and_alteration('Eb5')
# => {pitch: "Eb", octave: 5, alteration: "b"}

Note#pitch, octave, alteration, letter

→ String, Integer, String or nil, String

pitch includes the alteration. alteration is only the suffix and is nil for a natural note. letter is the letter name alone.

note = Musicalism::Note.new('C#4')
note.pitch                                # => "C#"
note.octave                               # => 4
Musicalism::Note.new('Bb3').alteration    # => "b"
Musicalism::Note.new('C4').alteration     # => nil
Musicalism::Note.new('F#5').letter        # => "F"

Note#to_midi

→ Integer from 21 to 108

Musicalism::Note.new('C#4').to_midi  # => 61
Musicalism::Note.new('E', 5).to_midi # => 76

Note#next

→ Note one semitone up · raises Note::UnkownNoteError past C8

Musicalism::Note.new('C#4').next  # => D4

Note#up_an_octave, down_an_octave

→ Note with the same spelling, one octave higher or lower

Musicalism::Note.new('G4').up_an_octave    # => G5
Musicalism::Note.new('G4').down_an_octave  # => G3

Note#transpose(semitones)

→ [Note], one per enharmonic spelling, all in octave 4

The octave is dropped: pick the spelling you need and set the octave yourself. Scales use this to give each degree the right letter.

Musicalism::Note.new('C4').transpose(4).map(&:pitch)  # => ["D##", "E", "Fb"]
Musicalism::Note.new('C4').transpose(6).map(&:pitch)  # => ["E##", "F#", "Gb"]

Note#interval_from(note)

→ Integer, the unsigned semitone distance between the two pitch classes

Octaves are ignored and so is the order of the notes. The count runs on an index that starts at A, so it is a distance within that index rather than a musical interval.

Musicalism::Note.new('C').interval_from(Musicalism::Note.new('G'))   # => 7
Musicalism::Note.new('B').interval_from(Musicalism::Note.new('B#'))  # => 1

Note#<=> and Comparable

compares MIDI numbers, so enharmonic notes are equal

Musicalism::Note.new('C4') < Musicalism::Note.new('C#4')    # => true
Musicalism::Note.new('C##4') == Musicalism::Note.new('D4')  # => true
Musicalism::Note.new('B#3') == Musicalism::Note.new('C4')   # => true

Interval

Named intervals as semitone counts. Create one generator and ask it for intervals: Musicalism::Interval.new.perfect_fifth returns 7. Enharmonic names are aliases. Some names keep their original spelling (perfect_forth, augmented_fith).

Scale

Four concrete scales share one interface. Scale itself has no structure, so use a subclass. Each degree gets the next letter name, so spellings stay correct in every key, and the octave goes up when the letter passes B, so notes always rise from the root.

ClassNotes from A
MajorScalemajor, from C: C4 D4 E4 F4 G4 A4 B4
MinorScalenatural minor: A4 B4 C5 D5 E5 F5 G5
HarmonicMinorScaleraised 7th: A4 B4 C5 D5 E5 F5 G#5
MelodicMinorScaleascending form, raised 6th and 7th: A4 B4 C5 D5 E5 F#5 G#5

MajorScale.new(root)

root is a Note or a name · → the scale; root_note reads it back

Scale#notes

→ [Note], seven degrees rising from the root

Musicalism::MajorScale.new('D').notes   # => D4 E4 F#4 G4 A4 B4 C#5
Musicalism::MajorScale.new('E#').notes  # => E#4 F##4 G##4 A#4 B#4 C##5 D##5

Scale#alterations

→ [String] in key-signature order: flats B E A D G C F, then sharps F C G D A E B

For harmonic and melodic minor the list includes the raised degrees, so it is not a key signature for those scales.

Musicalism::MajorScale.new('A').alterations          # => ["F#", "C#", "G#"]
Musicalism::MinorScale.new('F').alterations          # => ["Bb", "Eb", "Ab", "Db"]
Musicalism::HarmonicMinorScale.new('A').alterations  # => ["G#"]

Scale#degree_chord(degree, inversion: 0)

degree is one of Scale::DEGREES · → Chord

Stacks thirds over the scale laid out across two octaves, so every triad rises from its root. The degrees are :tonic, :supertonic, :mediant, :subdominant, :dominant, :submediant and :subtonic.

scale = Musicalism::MajorScale.new('C')
scale.degree_chord(:dominant)                # => G4 B4 D5
scale.degree_chord(:dominant, inversion: 2)  # => D5 G5 B5

Chord

An ordered list of notes. Triads are recognised in any inversion.

Chord.new(notes, inversion: 0)

→ Chord; notes reads the notes back

chord = Musicalism::Chord.new(%w[C4 E4 G4].map { |name| Musicalism::Note.new(name) })
chord.inspect  # => "#<Musicalism::Chord C4 E4 G4>"

Chord#quality, root, to_s

→ Symbol or nil, Note or nil, String

Quality is :major, :minor, :diminished or :augmented. For notes that are not a triad, quality and root are nil and to_s lists the pitches.

chord_of = ->(names) { Musicalism::Chord.new(names.split.map { |name| Musicalism::Note.new(name) }) }
chord_of['E4 G4 C5'].to_s      # => "C major"
chord_of['E4 G4 C5'].quality   # => :major
chord_of['E4 G4 C5'].root      # => C5
chord_of['C4 E4 G#4'].to_s     # => "C augmented"
chord_of['B4 D5 F5'].to_s      # => "B diminished"
chord_of['C4 D4 E4'].to_s      # => "C D E"

Chord#spelling, to_midi

→ [String], [Integer]

chord_of['C4 E4 G4'].spelling  # => ["C", "E", "G"]
chord_of['C4 E4 G4'].to_midi   # => [60, 64, 67]

Chord#inverse(depth), inverse!(depth)

→ a new Chord · the bang version changes the chord in place

Each step moves the lowest note up an octave.

chord_of['C4 E4 G4'].inverse(1).to_midi  # => [64, 67, 72]
chord_of['C4 E4 G4'].inverse(2)          # => G4 C5 E5

Chord#==

equal when the note lists are equal, note by note

Chord#voiced_near(previous)

→ Chord, the same chord in the inversion and octave closest to previous

Tries every inversion, up to two octaves either way, and keeps the voicing whose notes move the fewest semitones in total. Voicings outside A0..C8 are skipped.

chord_of['A4 C5 E5'].voiced_near(chord_of['C4 E4 G4']).to_midi  # => [60, 64, 69]

Chord.voice_lead(chords)

→ [Chord], the first chord as given, every next chord voiced near the one before

key = Musicalism::Key['C major']
Musicalism::Chord.voice_lead([key.chord(:I), key.chord(:IV), key.chord(:V), key.chord(:I)]).map(&:to_midi)
# => [[60, 64, 67], [60, 65, 69], [59, 62, 67], [60, 64, 67]]

Building a key

Key is the main API: start here, and drop to Scale only when you need it.

Key.major(tonic), minor(tonic), [name], new(tonic, mode)

tonic is a Note or a name · → Key · raises ArgumentError for a mode other than major or minor

Musicalism::Key.major('C')        # => C major
Musicalism::Key.minor('A')        # => A minor
Musicalism::Key['F# minor']       # => F# minor
Musicalism::Key['C dorian']       # raises ArgumentError, "dorian is not a key mode, use major or minor"

Key.coerce(key_or_name)

→ the Key itself, or a key built from its name

Every method that takes another key accepts a name too, through coerce.

Musicalism::Key.coerce('D minor')  # => D minor

Key#tonic, mode, major?, minor?, scale

→ Note, Symbol, booleans, MajorScale or MinorScale

key = Musicalism::Key['C major']
key.tonic        # => C4
key.mode         # => :major
key.major?       # => true
key.scale.class  # => Musicalism::MajorScale

Key#signature

→ [String], the altered pitches in key-signature order

Musicalism::Key['C major'].signature   # => []
Musicalism::Key['E minor'].signature   # => ["F#"]
Musicalism::Key['Eb major'].signature  # => ["Bb", "Eb", "Ab"]
Musicalism::Key['F# major'].signature  # => ["F#", "C#", "G#", "D#", "A#", "E#"]

Key#==, to_s, inspect

equal when the tonic is spelled the same and the mode matches; the octave does not count

Musicalism::Key['C major'] == Musicalism::Key.major('C')     # => true
Musicalism::Key['Db major'] == Musicalism::Key['C# major']   # => false
Musicalism::Key['C major'].inspect                           # => "#<Musicalism::Key C major>"

Related keys

Key#relative

→ Key: the relative minor a minor third below, or the relative major a minor third above

The relative of C4 major is A3 minor, and its relative is C4 major again, so walking back and forth never drifts.

key = Musicalism::Key['C major']
key.relative                 # => A minor, tonic A3
key.relative.relative.tonic  # => C4

Key#parallel

→ Key on the same tonic in the other mode

Musicalism::Key['C major'].parallel  # => C minor

Key#dominant_key, subdominant_key

→ Key, the neighbours a fifth up and a fifth down on the circle of fifths, in the same mode

These are keys, not chord functions. The tonic keeps its octave number, so walking the circle never leaves the MIDI range.

Musicalism::Key['C major'].dominant_key     # => G major
Musicalism::Key['C major'].subdominant_key  # => F major

Degrees and chords

Key#note(degree)

degree counts from 1 · → Note · raises ArgumentError below 1

Degrees past 7 go into the next octaves.

key = Musicalism::Key['C major']
(1..8).map { |degree| key.note(degree) }  # => C4 D4 E4 F4 G4 A4 B4 C5
key.note(9)                               # => D5
key.note(0)                               # raises ArgumentError, "degree must be 1 or more, got 0"

Key#chord(numeral, inversion: 0)

numeral from I to VII in either case · → Chord · raises ArgumentError for anything else

In minor keys, V and vii come from harmonic minor, so the dominant is major. Every other degree comes from natural minor.

key.chord(:V)                         # => G major, G4 B4 D5
key.chord(:V).to_midi                 # => [67, 71, 74]
key.chord(:vi, inversion: 1).to_midi  # => [72, 76, 81]
Musicalism::Key['A minor'].chord(:V)  # => E major
key.chord(:VIII)                      # raises ArgumentError, "VIII is not a roman numeral between I and VII"

Key#chords(function = nil)

→ [Chord]: all seven triads, or the chords of one harmonic function, primary chord first

FunctionDegreesIn C major
:tonicI vi iiiC major, A minor, E minor
:subdominantIV ii viF major, D minor, A minor
:dominantV viiG major, B diminished
Musicalism::Key['C major'].chords.map(&:to_s)
# => ["C major", "D minor", "E minor", "F major", "G major", "A minor", "B diminished"]
Musicalism::Key['A minor'].chords.map(&:to_s)
# => ["A minor", "B diminished", "C major", "D minor", "E major", "F major", "G# diminished"]
key.chords(:mediant)  # raises ArgumentError, "mediant is not a harmonic function, use tonic, subdominant or dominant"

Key#numerals

→ [Symbol], upper case for major and augmented chords, lower case otherwise

Musicalism::Key['C major'].numerals  # => [:I, :ii, :iii, :IV, :V, :vi, :vii]
Musicalism::Key['A minor'].numerals  # => [:i, :ii, :III, :iv, :V, :VI, :vii]

Modulation

Key#pivot_chords(destination)

→ [Pivot], the chords both keys spell the same way, best pivot first

Chords that are IV, ii or vi in the new key come first, then chords that are tonic in neither key, then chords that are I in either key. Enharmonic matches do not count here; see modulate_through for crossing the enharmonic seam.

Musicalism::Key['C major'].pivot_chords('G major').map(&:to_s)
# => ["A minor: vi in C major = ii in G major",
#     "E minor: iii in C major = vi in G major",
#     "C major: I in C major = IV in G major",
#     "G major: V in C major = I in G major"]
Musicalism::Key['C major'].pivot_chords('F# major')  # => []

Key#modulate_to(destination, via: nil, random: Random, voice_leading: true)

→ [Chord]: I, the pivot, V of the new key, I of the new key

  • By default the pivot is drawn at random from the shared chords that are tonic in neither key, so repeated calls vary. Pass random: Random.new(seed) to repeat a choice.
  • via: picks the pivot: a numeral in the key you leave, in either case, or a Pivot from pivot_chords. Only via: can use a tonic chord. A numeral that is not shared raises ArgumentError.
  • With no shared chord the progression goes straight from I to V and I of the new key.
  • The chords are voice-led from the opening I. voice_leading: false keeps each chord in root position in its own key's octave.
key = Musicalism::Key['C major']
key.modulate_to('G major', via: :vi).map(&:to_s)     # => ["C major", "A minor", "D major", "G major"]
key.modulate_to('G major', via: :vi).map(&:to_midi)  # => [[60, 64, 67], [60, 64, 69], [62, 66, 69], [62, 67, 71]]
key.modulate_to('G major', via: :vi, voice_leading: false).map(&:to_midi)
# => [[60, 64, 67], [69, 72, 76], [74, 78, 81], [67, 71, 74]]
key.modulate_to('G major', via: key.pivot_chords('G major').last).map(&:to_s)
# => ["C major", "G major", "D major", "G major"]
key.modulate_to('F# major').map(&:to_s)                # => ["C major", "C# major", "F# major"]
key.modulate_to('G major', via: :ii)                   # raises ArgumentError, "ii in C major is not a chord of G major"
I · C majorC major60 64 67
pivot · vi = iiA minor60 64 69
V · G majorD major62 66 69
I · G majorG major62 67 71

Pivot

A value object returned by pivot_chords, with chord, from_key, from_numeral, to_key and to_numeral.

pivot = Musicalism::Key['C major'].pivot_chords('G major').first
pivot.chord         # => A minor
pivot.from_numeral  # => :vi
pivot.to_numeral    # => :ii
pivot.to_s          # => "A minor: vi in C major = ii in G major"

Key graph

A step on the graph is a modulation to the dominant, subdominant or relative key. Each step has a pivot chord. The graph compares keys by pitch class and mode, so F# major and Gb major are the same place. The key graph guide has an interactive wheel.

Key#closely_related

→ [Key]: dominant, subdominant and relative, respelled, in the starting key's octave

Musicalism::Key['C major'].closely_related   # => G major, F major, A minor
Musicalism::Key['A minor'].closely_related   # => E minor, D minor, C major
Musicalism::Key['F# major'].closely_related  # => Db major, B major, D# minor

Key#simplest_spelling

→ Key, the enharmonic spelling with the fewest accidentals; a tie keeps the current spelling

Musicalism::Key.major('C#').simplest_spelling  # => Db major
Musicalism::Key.major('Cb').simplest_spelling  # => B major
Musicalism::Key.minor('A#').simplest_spelling  # => Bb minor
Musicalism::Key.major('F#').simplest_spelling  # => F# major

Key#distance_to(other)

→ Integer, the fewest steps between the two keys

key = Musicalism::Key['C major']
key.distance_to('G major')   # => 1
key.distance_to('D major')   # => 2
key.distance_to('F# major')  # => 6
key.distance_to('Eb minor')  # => 7

Key#path_to(destination, random: Random)

→ [Key], one shortest path, starting with the key and ending with the destination as you spelled it

key.path_to('F# major', random: Random.new(1))
# => C major, F major, Bb major, Eb major, Ab major, Db major, F# major
key.path_to('C major')  # => [C major]

Key#modulate_through(keys, random: Random, voice_leading: true)

→ [Chord], modulate_to chained along the keys, sharing the I chord between two hops

A leading copy of the key itself is skipped, so you can pass a path_to result directly. Each hop respells the next key to share the most chords with the current one, so crossing from F# major to Db major still goes through a pivot.

key.modulate_through(key.path_to('D major')).map(&:to_s)
# => ["C major", "E minor", "D major", "G major", "B minor", "A major", "D major"]
Musicalism::Key['F# major'].modulate_through(['Db major']).map(&:to_s)
# => ["F# major", "D# minor", "G# major", "C# major"]

Micro modulations

Short tonicizations that borrow from a passing key for a beat or a bar and leave the key itself unchanged.

Key#tonicize(numeral)

→ Key built on that degree's chord · raises ArgumentError for a diminished or augmented degree

key = Musicalism::Key['C major']
key.tonicize(:ii)                       # => D minor
Musicalism::Key['A minor'].tonicize(:V) # => E major
key.tonicize(:vii)                      # raises ArgumentError, "vii in C major is a diminished chord, it cannot be a local tonic"

Key#secondary_dominant(numeral)

→ Chord, the V of the key on that degree

key.secondary_dominant(:V)    # => D major, V/V
key.secondary_dominant(:vi)   # => E major, V/vi
Musicalism::Key['A minor'].secondary_dominant(:iv)  # => A major

Key#two_five(numeral)

→ [Chord], ii and V of the key on that degree; a minor target gets ii°

key.two_five(:IV)  # => G minor, C major
key.two_five(:V)   # => A minor, D major
key.two_five(:ii)  # => E diminished, A major
